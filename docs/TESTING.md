# 测试清单

在发布前，请逐项验证。建议在 **Chrome** 与 **Edge** 各测一遍。

## 1. 加载扩展

```bash
npm run build
```

1. 打开 `chrome://extensions`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择 `dist` 目录
4. 确认扩展图标出现，无报错

## 2. 基础朗读（Web Speech）

| 步骤 | 预期结果 |
|------|----------|
| 打开任意新闻/文章页 | 正常加载 |
| 选中一段中文 | 选区高亮 |
| 右键 → **Read This / 朗读此内容** | 底部播放器出现并开始朗读 |
| 点击暂停 / 播放 | 朗读暂停与恢复 |
| 点击停止 ■ | 朗读停止 |
| 拖动语速滑块 | 语速变化（新朗读生效） |
| 点击 ✕ 关闭播放器 | 播放器消失 |

## 3. 快捷键

| 步骤 | 预期结果 |
|------|----------|
| 选中文字后按 **Alt+R** | 开始朗读 |
| 在 `chrome://extensions/shortcuts` 查看 | 显示 Voicer 快捷键 |

## 4. 设置持久化

| 步骤 | 预期结果 |
|------|----------|
| Popup 中修改语速为 1.5x | 显示已保存 |
| 刷新页面 / 新开 tab / 重启浏览器 | 语速仍为 1.5x |
| 切换界面语言为 English | 播放器与菜单文案变为英文 |

## 5. Popup / Options

| 步骤 | 预期结果 |
|------|----------|
| 点击扩展图标 | Popup 正常显示 |
| 切换 TTS 引擎 | 保存成功 |
| 点击「高级设置」 | 打开 Options 页 |
| 填写 HTTP 端点并保存 | 刷新后仍保留 |

## 6. 长文分段

| 步骤 | 预期结果 |
|------|----------|
| 选中 >5000 字文本 | 播放器显示分段进度（如 1/3） |
| 全文朗读 | 各段依次播放 |

## 7. HTTP / Azure（可选）

| 步骤 | 预期结果 |
|------|----------|
| 配置有效 ChatTTS 端点，引擎选 HTTP | 返回音频并播放 |
| 断开 ChatTTS 服务 | 自动降级 Web Speech，显示降级提示 |
| 配置 Azure Key（如有） | 合成并播放 |

## 8. 兼容性

- [ ] 普通网页（如 Wikipedia、知乎）
- [ ] 深色模式网站
- [ ] 播放器不被页面 CSS 覆盖（Shadow DOM）
- [ ] `chrome://` 页面无法注入（预期行为，不报错即可）

## 9. 控制台

打开 DevTools → Console，执行朗读时：

- [ ] 无 uncaught error
- [ ] Service Worker 无 persistent 报错（`chrome://extensions` → 检查视图）

全部通过后，执行 `npm run package` 生成发布包，进入 [RELEASE.md](./RELEASE.md) 流程。
